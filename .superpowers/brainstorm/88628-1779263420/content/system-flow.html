🌅 Flow A — Daily message delivery

① Generation (overnight prep)

  1. Cron fires hourly → matches users whose local push-time == "now"
  2. Load child stage + chat summary + last-7-days topics
  3. LLM picks kind (video/tip/quote/book)
  4. Vector search content_items (locale + stage + topic)
  5. LLM writes 2-3 sentence personal framing
  6. Insert daily_messages row
Vercel Cron · Queues · AI Gateway · Postgres+pgvector

② Push delivery

  1. Worker calls Expo Push API with token + title + body
  2. Expo fans out → APNs (iOS) + FCM (Android)
  3. Notification surfaces on lock screen

Key takeaways

  • Daily message is async — generated in the background, not when the user opens the app. Push is the trigger.
  • Chat is real-time streaming — user sees tokens appear as they're generated. No "thinking…" spinner.
  • Memory is incremental — rolling summary keeps context bounded even after 1000s of messages. No re-reading full history.
  • Safety is layered, not blocking — model escalation + resource pointer, but the AI always engages warmly. Never "I can't help with that."
  • Open/save signals improve relevance — every tap teaches the daily-message generator what this parent values.
