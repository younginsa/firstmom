🌅 Daily message generation flow (runs hourly via Cron)

  1. Cron fires every hour → finds users whose local preferred delivery time matches
  2. For each user: fetch child stage + recent chat summary + last 7 daily topics
  3. LLM picks: format (tip / video / quote / book / news) + topic (related to chat or seasonal)
  4. LLM queries content library with constraints → picks 1 verified link
  5. LLM writes warm personalized framing around the link
  6. Persist daily_message row → send Expo push → tapping opens Today screen

💬 Chat flow (real-time, streaming)

  1. User sends message → /api/chat receives userId + threadId + text
  2. Backend assembles: system prompt (Warm Friend + stage context) + memory summary + recent turns + new message
  3. AI SDK streams response from AI Gateway (Claude Haiku default for cost; escalate to Sonnet for hard topics)
  4. Safety filter checks for medical/mental health/abuse signals → appends professional-resource pointer
  5. After thread crosses N turns, async job updates the rolling memory summary
