Flow logic

  1. First open → Onboarding (#1) → land on Today (#2)
  2. Push notification at user's set time → tap → opens Daily detail (#3)
  3. From daily → "이것 관련 대화" button → opens Chat (#4) with topic pre-loaded
  4. Chat is always one continuous thread per child (no thread management in v1)
  5. Library (#5) groups all past dailies + saved items + recent chat topics
  6. Me (#6) controls push time, language, privacy, and (v2) which child

Click any phone to flag for changes, or just tell me in the terminal.
