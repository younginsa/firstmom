What changed vs the previous mockups
  • Navigation bar with pill-shaped active indicator (M3 standard) instead of bare icons
  • Large top app bar with greeting + date — proper M3 hierarchy, not just a centered title
  • Tonal surfaces — cards use Surface-Container-Highest, not bare white
  • M3 chips with proper 32dp height + leading checkmark when selected
  • List items with leading icon + headline + supporting text + trailing — true M3 anatomy
  • FAB (Floating Action Button) for "start new chat" on Home — primary action discoverable
  • M3 text input on chat with leading attach + trailing send (proper input bar pattern)
  • 8dp grid + 16dp screen padding consistently applied
  • Type scale follows Material 3 — Display/Headline/Title/Body/Label sizes, not arbitrary
